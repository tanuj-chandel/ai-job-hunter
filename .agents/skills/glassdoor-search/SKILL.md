# Glassdoor Search Skill

Use this skill to search live job listings across Glassdoor for operations, warehouse, supply chain, and corporate management roles.

## CLI Usage

```bash
bun run .agents/skills/glassdoor-search/cli/src/cli.ts search -q "Operations Manager" -l "Dubai" -n 15 --format json
```
